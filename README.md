# Медичний центр «Атланта» — сайт

Односторінковий лендинг стоматологічної клініки в Кам'янці-Подільському. Статичний HTML, без збірки — можна відкрити `index.html` напряму або задеплоїти на GitHub Pages без жодних кроків збірки.

## Деплой на GitHub Pages

1. Створіть репозиторій на GitHub і запуште цю папку.
2. Settings → Pages → Source: `main` / `/ (root)`.
3. Сайт з'явиться на `https://<username>.github.io/<repo>/`.

## Заявки з форм → Telegram (потрібно активувати)

Форми (`#appointForm` і `#modalForm`) вже підключені до відправки, але їм потрібен робочий приймач — заповніть 3 кроки нижче, інакше заявки нікуди не підуть.

**1. Створіть Telegram-бота**
Напишіть [@BotFather](https://t.me/BotFather) → `/newbot` → скопіюйте виданий токен (виглядає як `123456:AA...`).

**2. Дізнайтесь chat_id**
Додайте бота в чат/групу, куди мають приходити заявки, напишіть туди будь-яке повідомлення, потім відкрийте в браузері:
`https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
У відповіді знайдіть `"chat":{"id": ...}` — це і є `chat_id` (для групи буде від'ємне число).

**3. Задеплойте проксі (Cloudflare Workers, безкоштовно)**
Токен бота не можна вставляти прямо в `index.html` — його побачить будь-хто через "Переглянути код сторінки" і зможе слати повідомлення від імені бота. Тому заявки йдуть через маленький проксі-сервер, який тримає токен у секреті.

- Зареєструйтесь на [dash.cloudflare.com](https://dash.cloudflare.com) (безкоштовно, картка не потрібна) → Workers & Pages → Create → Create Worker.
- Відкрийте редактор коду Worker'а, вставте вміст файлу [`telegram-proxy/worker.js`](telegram-proxy/worker.js) з цього репозиторію, натисніть Deploy.
- Settings → Variables and Secrets → додайте два secrets: `TELEGRAM_BOT_TOKEN` (з кроку 1) і `TELEGRAM_CHAT_ID` (з кроку 2).
- Скопіюйте URL воркера (виду `https://atlanta-leads.<ваш-акаунт>.workers.dev`).
- У `index.html` знайдіть рядок `const LEAD_ENDPOINT='https://REPLACE-WITH-YOUR-WORKER.workers.dev';` і вставте туди свій URL.

Після цього кроку кожна заявка з сайту буде приходити повідомленням у ваш Telegram-чат. Якщо запит не вдався (наприклад, воркер ще не налаштований), відвідувач побачить попередження з проханням зателефонувати — заявка більше не «губиться» мовчки.

## Інші знахідки аудиту (28.07.2026)

SEO (немає Open Graph / structured data), продуктивність (немає `srcset`/`preload` для hero-фото), юридична частина (посилання на політику обробки персональних даних відсутнє, хоча форма на неї посилається) — див. повний звіт аудиту. Доступність модального вікна (відсутні `id`/`for` на полях) вже виправлено разом з підключенням форм.

## Структура

```
atlanta-site/
├── index.html            — весь сайт (HTML + CSS + JS в одному файлі)
├── telegram-proxy/
│   └── worker.js          — Cloudflare Worker: приймає заявки, шле в Telegram
├── README.md
└── .gitignore
```

## Зовнішні залежності

Сайт хотлінкить зображення (Unsplash, s.3849.com.ua CDN) та шрифти (Google Fonts) — інтернет-з'єднання потрібне навіть локально, свого сервера зображень немає.
